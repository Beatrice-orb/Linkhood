# 搭把手 —— 社区生活地图


## 📖 项目简介

**「搭把手」是一个社区生活信息平台**，以“社区生活地图”为核心，整合社区公共空间、活动信息、周边服务和社工服务，解决居民“搬进来不知道社区有什么”“住了很久不知道周边能干什么”的信息不对称问题。平台同时通过邻里圈的互助和社交功能，促进邻里互动，降低社区治理成本。

### 产品定位

> **“一个社区，应该有一张地图。”**

### 目标用户

- **居民端**：全年龄段社区居民（新住户、独居青年、有孩家庭、中老年住户、养宠人群）
- **管理端**：物业公司、居委会/街道办、青年公寓运营方

### 商业模式

**B2G2C** —— 政府/街道付费采购，免费提供给居民使用。

| 客户 | 付费逻辑 |
|---|---|
| 街道办/镇政府 | 12345降诉、基层治理创新、数据化决策 |
| 物业公司 | 业主满意度提升、工作效率提高 |
| 青年公寓运营方 | 续租率提升、住户活跃度提高 |

**定价模式**：年费制 SaaS，1-20万/年（按覆盖社区数和功能版本分层）


## ✨ 核心功能

### 居民端（微信小程序）- 普通版

| 模块 | 功能 | 说明 |
|---|---|---|
| **社区地图** | 公共空间 | 查看所有公共空间（位置/开放时间/设施/预约方式/评价），支持分类筛选和收藏 |
| | 本周活动 | 查看本周活动，在线报名，报名后自动进入活动群聊 |
| | 周边服务 | 查看周边商家（位置/电话/营业时间/住户推荐/优惠），一键导航/拨号 |
| | 社工服务 | 查看社工/楼栋管家信息（负责区域/值班时间/服务范围），一键联系 |
| **顶部悬浮区** | 当前居住 | 查看当前社区+楼栋信息 |
| | 最新公告 | 查看物业/居委会发布的社区公告，未读红点提醒 |
| | 新手指南 | 8步引导新住户快速了解社区全貌 |
| **邻里圈** | 邻里互助 | 发布/响应拼单、代取、照看、闲置等互助需求 |
| | 日常动态 | 发布/浏览邻里日常分享、生活共鸣 |
| | 小活动召集 | 发布/参与非正式社区活动 |
| **我的聊天** | 活动群聊 | 报名活动后自动加入活动群聊 |
| | 互助对话 | 响应互助后自动建立对话 |
| | 私聊 | 从邻里圈点击头像发起私聊 |
| | 系统通知 | 活动提醒、评论通知、公告推送 |
| **我的** | 个人中心 | 头像/昵称/楼栋/兴趣标签 |
| | 信用体系 | 信用分 + 互助积分 + 成就徽章 |
| | 记录管理 | 我的发布/我的帮助/我的活动/收藏 |
| **喊一声** | 快速发布 | 找人搭把手 / 一起拼单 / 发条日常 / 组个小活动 |

### 居民端（微信小程序）- 关怀版（适老化版本）

**定位**：专为老年人及不擅长使用智能手机的居民设计。

**产品Slogan**：**“有事有人管，没事有人陪。”**

| 变化维度 | 普通版 | 关怀版 |
|---|---|---|
| 底岛Tab | 4个 | **3个**（首页/邻里圈/我的） |
| 发布类型 | 4种 | **2种**（求助+动态） |
| 聊天功能 | 独立底岛+主动聊天 | 分散入口+被动接收+快捷回复 |
| 全局字体 | 默认 | **放大至36-40rpx** |
| 按钮高度 | 44rpx | **64rpx以上** |

**关怀版独有功能**：

| 功能 | 说明 |
|---|---|
| 🆘 **一键呼救（SOS）** | 所有页面右下角大红色悬浮按钮，三级响应机制（紧急联系人→社工→物业安保） |
| 📢 **防诈骗提醒** | 首页顶部轮播，每日更新一条防诈骗提示 |
| ✅ **每日报平安** | 一键报平安，自动通知守护人；超24小时未报平安自动提醒 |
| 🛡️ **安全守护人** | 设置子女/亲属为守护人，接收呼救/报平安/用药提醒 |
| 📋 **申请帮扶** | 代买菜/代买药/家电维修/家政清洁/上门理发等，表单仅3个字段 |
| 💊 **用药记录本** | 药品管理+定时吃药提醒+打卡记录，子女可远程查看 |
| 📖 **办事指南** | 医保报销/养老金认证/高龄补贴申请等图文教程 |
| ❓ **政策问答** | 常见政策问题Q&A，一键拨号咨询 |
| 🌺 **小红花** | 替代积分，通过报平安/按时吃药/参加活动等获得 |
| ⭐ **好评数** | 替代信用分，直观展示被邻居好评次数 |
| 👥 **关怀圈** | 邻里圈专属Tab，老年兴趣社团/志愿者陪伴/健康知识 |

### 技术选型

| **小程序端** | 微信小程序原生框架 + WeUI | 微信官方生态，性能最优 |

## 🚀 快速开始

### 前置条件

- Node.js 18+
- MySQL 8.0+
- Redis 7.0+
- 微信开发者工具
- 微信小程序 AppID

### 1. 克隆项目

```bash
git clone https://github.com/yourusername/dabashou.git
cd dabashou
```

### 2. 项目结构

```
dabashou/
├── miniprogram/          # 小程序端
│   ├── pages/
│   │   ├── map/         # 社区地图
│   │   ├── circle/      # 邻里圈
│   │   ├── chat/        # 我的聊天
│   │   ├── mine/        # 我的
│   │   └── care/        # 关怀版（适老化版本）
│   ├── components/      # 公共组件
│   ├── utils/           # 工具函数
│   ├── api/             # 接口封装
│   └── app.js           # 小程序入口
├── admin/               # 管理后台
│   ├── src/
│   │   ├── pages/       # 页面
│   │   ├── components/  # 组件
│   │   └── api/         # 接口
│   └── package.json
├── server/              # 后端服务
│   ├── src/
│   │   ├── modules/     # 业务模块
│   │   ├── common/      # 公共模块
│   │   └── config/      # 配置文件
│   └── package.json
├── database/            # 数据库脚本
│   ├── schema.sql
│   └── mock_data.sql
├── docker/              # Docker配置
└── README.md
```

### 3. 后端启动

```bash
cd server
npm install

# 配置环境变量
cp .env.example .env
# 编辑 .env 配置数据库连接等信息

# 数据库迁移
npm run migration:run

# 启动开发服务
npm run start:dev
```

### 4. 管理后台启动

```bash
cd admin
npm install
npm run dev
```

### 5. 小程序启动

1. 用**微信开发者工具**打开 `miniprogram` 目录
2. 修改 `app.js` 中的 API 地址为本地后端地址
3. 点击“编译”即可预览

### 6. Docker 部署（生产环境）

```bash
docker-compose up -d
```
